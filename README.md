# Shoebot V2
## Introduction
Scrapes a climbing shoe website to update a user on stock/sale changes.<br>
Discord bot token & channel to be set up by individual users.<br>
After setting up the Discord bot, shoecord.py is the only Python program that needs to be run.

## Overview
Additional libraries used (Can be downloaded using pip install):
  - BeautifulSoup4
  - SQLite3
  - Requests
